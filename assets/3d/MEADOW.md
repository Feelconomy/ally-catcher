# Meadow Background

Higgsfield 3D Jutsu project aeeb0fce-a7b9-4678-b6af-6ce3071318e4, revision 8.
Authored meadow environment based on the previously generated sunny meadow reference.
Includes terrain, curved grass, flowers, trees, stones, clouds and embedded normal maps.

This change adds only the background. Existing prize models, cabinet materials,
lighting, controls, stock behavior and 2D modes are retained from main.
Imported environment lights and cameras are removed so they cannot override the game.
