# 초록 캐릭터 데스크톱 펫 픽셀아트 에셋

참고 그림의 연두색 캐릭터를 바탕으로 만들고, 두 번째 참고 이미지처럼 굵고 단순한 사각 픽셀 스타일로 다시 다듬은 투명 배경 RGBA PNG 에셋입니다.

- `poses/`: 128×128 픽셀 동작/표정 16종. 모든 프레임은 같은 캔버스에 발 위치를 맞췄습니다.
- `props/`: 96×96 픽셀 소품/효과 16종.
- `poses_atlas.png`, `props_atlas.png`: 각각 4열×4행 아틀라스.
- `manifest.json`: 파일 경로와 추천 애니메이션 순서.
- `source/`: 새 스타일의 원본 시트와 배경을 제거한 시트. 개별 파일은 이를 분리해 4×4 물리 픽셀 단위로 크기를 맞춘 것입니다.

앱에서 확대할 때는 **nearest-neighbor** 필터를 사용하세요. `walk_left_1`과 `walk_left_2`를 반복하고, 오른쪽으로 이동할 때는 해당 프레임을 수평으로 뒤집으면 됩니다. `idle`과 `breathe`를 번갈아 표시하고 가끔 `blink`를 넣으면 기본 대기 동작이 됩니다. 모든 프레임은 투명 배경이며, 그림자 효과는 `props/shadow.png`를 캐릭터 아래에 배치하세요.

이미지 생성 방식의 픽셀아트이므로 동작별 윤곽에 작은 차이가 있습니다. 정밀한 프레임 단위 애니메이션이 필요하다면 손으로 윤곽을 통일하는 작업을 권장합니다.
