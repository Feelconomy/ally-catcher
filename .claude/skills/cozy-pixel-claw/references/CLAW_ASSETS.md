# Claw Assets System
## Pixel Assets for a Playful Claw-Machine Mobile Web

This file defines the asset vocabulary for a toy-arcade / plush-catcher product.
Use it to guide illustration, UI component styling, sprite creation, and screen-specific content.

---

# 1. Visual identity summary
The app should feel like:
- a colorful pixel toy arcade
- a mobile-friendly crane game interface
- a collectible plush world
- a reward-rich but readable consumer game

Key surface language:
- rounded-but-pixelated marquee plaques
- acrylic machine windows
- cute prize pods and shelves
- soft candy colors with strong outlines
- chunky buttons, tokens, and tickets
- sparkles, confetti, bulb lights, and celebratory bursts

# 3. Asset production rules
- use fixed pixel grids
- keep toys readable from thumbnail size
- machine windows should look acrylic / transparent but still pixel crisp
- rewards should be more detailed than utility icons
- lights and confetti must enhance feedback, not obscure information
- use playful color, but preserve functional hierarchy
