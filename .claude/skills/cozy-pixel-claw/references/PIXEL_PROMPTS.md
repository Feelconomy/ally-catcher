# Pixel Prompts Pack
## Prompt templates for a playful claw-machine mobile web

Use these prompts to generate original pixel-art assets for a claw-machine / plush-catcher product.

---

# 1. Global style rules
Always reinforce:
- original playful pixel-art UI style
- crisp hard-edged pixel clusters
- no anti-aliasing
- toy-like and arcade-like atmosphere
- chunky readable silhouettes
- bright candy palette with controlled hierarchy
- subtle 1-pixel highlights
- transparent background for standalone assets
- no watermark
- no copied branded characters or machine decals

Negative guidance:
- no photorealism
- no 3D render
- no vector-flat app icon style
- no blurry glow overuse
- no smooth painterly shading
- no muddy palettes

# 11. Prompt tuning notes
If too childish:
```text
Increase polish and clarity, keep the toy-like mood but make the UI feel premium and intentional rather than babyish.
```

If too noisy:
```text
Reduce confetti and blinking-light detail, keep the hierarchy cleaner so machine information and buttons remain highly readable.
```

If too flat:
```text
Add more layered frame depth, acrylic-machine material cues, button volume, and stronger pixel highlights.
```

If not playful enough:
```text
Strengthen the arcade and toybox mood with marquee lights, plush prizes, ticket/coin motifs, and celebratory reward accents.
```
