# Asset Production Roadmap
## Cozy Pixel Claw / Toy Arcade Domain

This roadmap prioritizes what to build first for a claw-machine mobile web.

---

# 1. Production goals
Phase the work so the team can ship:
1. a clear login and lobby
2. a playable machine flow
3. a satisfying result and collection loop
4. retention systems like missions and attendance
5. later expansion packs for prize series and events

---

# 2. MVP target
For a strong first release, aim for:
- frames and UI shells: 12–15
- buttons / controls: 12–18
- utility icons: 40–50
- machine assets: 12–16
- plush / prize assets: 24–40
- reward / FX assets: 12–16
- collection / mission assets: 20+
- decorative environment assets: 15–20
- guide mascot poses: 6

Approximate MVP total: **150–180 assets**

---

# 3. Build phases
## Phase 0 — Direction lock
Confirm:
- product tone: cute vs premium vs energetic
- main palettes: Candy, Sky, Honey at minimum
- character policy: subtle mascot + plush-first
- core prize series for launch

## Phase 1 — Foundation
Build first:
- page frames
- popups
- wallet bar
- buttons
- tabs
- bottom navigation
- general icon family

## Phase 2 — Gameplay essentials
Build next:
- machine shell family
- chamber interior
- claw states
- controls set
- timer / power bars
- result popups
- success / fail FX

## Phase 3 — Prize ecosystem
Build next:
- core plush lineup
- capsule items
- rarity badges
- new / duplicate / limited states
- prize detail card assets

## Phase 4 — Collection and retention
Build next:
- display cabinet
- inventory slot family
- mission board
- attendance card
- milestone reward strip
- claimable chests

## Phase 5 — Monetization / support
Build next:
- currency pack cards
- coupon cards
- premium offer frames
- settings / support lighter shells

## Phase 6 — Expansion
Build later:
- event machines
- seasonal prize variants
- ranking podium art
- extra plush families
- event banners

# 5. Prize production strategy
Do not draw 100 unrelated plushies immediately.
Use a series approach.

Launch recommendation:
- 1 core plush series with 5 characters
- 1 dessert or event series with 4 characters
- 2–4 color/rarity variants
- 1 jackpot premium variant

This creates perceived abundance with manageable effort.

---

# 6. QA checklist
## Clarity
- can players find the play CTA instantly?
- is currency clear?
- are machine states understandable?

## Reward feel
- does a win feel satisfying?
- do rare items feel special?
- is replay motivation visible?

## Pixel integrity
- no blurred edges
- no random outline inconsistency
- no unreadable tiny toy details

## Mobile usability
- controls are touch-friendly
- important actions remain clear under excitement FX
- screen density does not overwhelm smaller devices
