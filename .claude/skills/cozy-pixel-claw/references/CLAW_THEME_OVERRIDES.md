# Claw Theme Overrides
## Theme usage specific to the claw-machine domain

Use `cozy-pixel-core` themes as the base, but apply them with arcade priorities.

---

# 1. Primary domain themes
## Candy
Default main theme for login, lobby, and machine browsing.
Use for:
- playful first impression
- soft candy arcade tone
- prize-centric screens

## Sky
Use for:
- machine play screen
- clean readability
- toybox atmosphere
- blue machine shells and controls

## Peach
Use for:
- onboarding
- community/light social surfaces
- collection cabinet warmth

## Berry
Use for:
- event banners
- rankings
- limited-time or festival pages

## Honey
Use for:
- jackpots
- premium rewards
- recharge / monetary emphasis
- mission milestones

---

# 2. Screen recommendations
- Login: Candy / Peach
- Lobby: Candy / Sky
- Machine list: Candy / Sky
- Play: Sky primary + Candy accents
- Result success: Honey + active theme accents
- Result fail: softer active theme with reduced saturation
- Collection: Peach / Candy / Lavender accents
- Missions: Sky / Honey
- Attendance: Peach / Honey
- Shop: Honey / Sky
- Ranking/Event: Berry / Honey

---

# 3. Intensity tuning
## Full
Use for:
- login
- lobby
- event pages
- win result screens
- collection hero moments

## Medium
Use for:
- gameplay HUD
- shop
- missions
- my page
- wallet pages

## Light
Use for:
- settings
- support
- legal / FAQ
- transaction history

---

# 4. What not to overdo
Avoid:
- using bright pink on every component equally
- applying flashing / glowing treatment to all panels
- making every screen a confetti explosion
- darkening the UI until it becomes a neon cyber aesthetic

This pack should feel **playful and premium**, not chaotic.
