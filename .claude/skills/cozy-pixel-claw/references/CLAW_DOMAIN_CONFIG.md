# Claw Domain Config
## Cozy Pixel Claw / Arcade / Plush Catcher Pack

---

# 1. Domain identity

```yaml
domain: Claw Machine Mobile Web / Arcade Collectible Game
product_jobs:
  - browse available claw machines
  - log in and maintain account / tickets / coins
  - play machines with touch controls
  - receive results and rewards
  - collect plushies, figures, capsules, and event items
  - manage inventory / gift / showcase items
  - complete missions and attendance rewards
  - compare rankings or participate in seasonal events
primary_emotion:
  - playful
  - exciting
  - rewarding
  - cute
  - toy-like
  - tactile
recommended_intensity: Full
```

---

# 2. Domain metaphor
The strongest metaphor is:

> **Toy Arcade Plaza**

A bright miniature arcade world where each machine feels like a stall or attraction, and the user's collection area feels like a trophy room / display cabinet.

Sub-metaphors:
- **Prize Cabinet** for inventory / collection
- **Ticket Booth** for currency / recharge
- **Mission Board** for tasks / attendance
- **Festival Event Hall** for limited-time campaigns

Do not mix in reading-room, forest-library, or office-dashboard metaphors.

---

# 3. UX tone
- immediately understandable on mobile
- cheerful, toy-like, and energetic
- feedback-rich without being visually exhausting
- jackpot excitement balanced with readable UI
- collection value should feel high

---

# 4. Semantic content model
Primary entities:
- user
- machine
- prize
- play session
- token / coin / ticket
- inventory item
- mission
- attendance reward
- event
- ranking
- gift / coupon

Important states:
- available / sold out / maintenance
- ready / aiming / dropping / grabbed / failed / success / jackpot
- new prize / owned / duplicate / locked / limited
- mission incomplete / claimable / completed

---

# 5. Reward vocabulary
Success means:
- catching a prize
- landing a near-win and trying again
- completing a collection set
- daily attendance streaks
- mission completion
- milestone jackpots
- ranking or event placement

Corresponding reward objects:
- plush badge
- jackpot star
- gold ticket
- confetti plaque
- shining capsule
- collector ribbon
- attendance stamp
- mission trophy

---

# 6. Character policy
Recommended choice:
- **subtle mascot + plush-centered system**

Interpretation:
- 1 optional guide mascot for onboarding / empty states
- the real stars are the collectible plush characters and prize series
- avoid one mascot overshadowing the prize ecosystem

---

# 7. Theme policy
Primary theme families:
- Candy
- Peach
- Sky
- Berry
- Honey (reward)

Use Night only for special events or night-arcade scenes.

---

# 8. Forbidden inheritance
Do not inherit from other packs:
- books
- shelves full of reading props
- quote cards
- librarian characters
- tea-table reading motifs
- nature-growth habit motifs unless they are event-limited and clearly adapted

---
