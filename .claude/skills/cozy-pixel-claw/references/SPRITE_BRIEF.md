# Sprite Brief
## Plush, Guide Mascot, and Prize Family Direction for a Claw-Machine Mobile Web

This file defines character policy for the claw domain.
The goal is to create a collectible, playful toy ecosystem rather than one overpowering mascot brand.

---

# 1. Character system goal
Characters must support:
1. onboarding guidance
2. prize desirability
3. emotional reward
4. seasonal variation
5. collection and sharing appeal

---

# 2. Character system structure
Recommended layers:

## A. Guide mascot
One optional friendly guide character used in onboarding, empty states, and mission / attendance hints.

## B. Prize families (most important)
Multiple plush series that become the true collectible stars.

## C. User avatar (optional)
Very light use if profile/social features exist.

---

# 3. Guide mascot direction
Because the product is a claw-game, the guide mascot should not overshadow the prize lineup.
Choose something simple and charming.

Strong recommendation:
> **A tiny arcade helper cat or rabbit wearing a toy-booth cap**

Why:
- readable in small UI moments
- can act as an attendant / helper
- blends naturally into arcade signage
- does not dominate the collectible ecosystem

# 4. Prize family strategy
The collectible prize families are more important than the guide mascot.
Create several distinct but compatible series.

### Series B — Dessert Mochis
- strawberry mochi

- cream cloud
- donut chick
Palette: Candy / Peach

### Series C — Star Dreamers
- moon bunny
- star bear
- cloud chick
- comet cat
Palette: Lavender / Sky / Honey

### Series D — Tiny Arcade Crew
- ticket puppy
- coin hamster

- standard pose

- event costume variant

---

# 5. Plush design rules
- rounded toy-like silhouette
- soft stuffed feel through shading and seams
- readable at thumbnail size
- limited palette per plush
- avoid overly thin limbs or fragile details
- expression should be cute and clear with minimal facial pixels

Outline direction:
- warm cocoa or plum-brown outline
- not pure black by default

Lighting:
- top-left light
- 1-pixel highlight for shine / toy polish where appropriate

---

# 6. Optional user avatar system
Use only if community/profile is important.

If used:
- 3 to 4 heads tall chibi proportion
- simple arcade-going outfits
- handheld plush / token / ticket accessories
- not more visually prominent than prize plushies

Recommended minimum avatar pack:
- 6 hairstyles
- 6 outfits
- 4 accessories
- 4 props
- 4 expressions
