# Color Themes
## Generic multi-domain palette system

Theme is separate from domain. A finance app may use Ocean; a travel app may use Honey. Choose based on product mood, not only category.

---

# 1. Forest
Colors:
- moss `#6f8a3d`
- olive `#8fa24d`
- fern `#99bd63`
- bark `#8b6b46`
- cream `#fff4d9`

Mood:
- natural
- calm
- warm
- growth-oriented

Works well for:
- habits
- wellness-lite
- reading
- sustainability
- community

# 11. Theme usage rule
Within a screen:
- base neutral: 60–75%
- primary theme: 15–30%
- secondary accent: 5–10%
- reward/glint: tiny amount only

Do not use all palette colors equally.
