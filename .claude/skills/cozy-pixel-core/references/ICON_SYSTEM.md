# Icon System
## Generic semantic pixel icon framework

---

# 1. Standard sizes
- 16x16: micro status
- 24x24: compact controls
- 32x32: standard navigation/action
- 48x48: featured action/category

---

# 2. Construction
Each icon family should share:
- outline color family
- light direction
- detail density
- baseline alignment
- visual weight

Icons should be recognizable by silhouette before decorative detail.

---

# 3. Universal icon categories

## Navigation
- home
- search
- back
- next
- menu
- profile
- settings
- notification
- calendar
- favorites

## Actions
- add
- edit
- delete
- save
- share
- filter
- sort
- refresh
- check
- close
- upload
- download

## Utility
- clock
- envelope
- location
- lock
- unlock
- info
- warning
- success
- error
- link

Domain packs add semantic categories beyond these.

---

# 4. Active state
Use at least one non-color change:
- plaque behind icon
- sparkle marker
- selected frame
- 1–2 px positional lift
- small badge

---

# 5. Generic icon prompt
```text
Original cozy pixel-art UI icon, highly readable, crisp hard-edged pixel clusters,
no anti-aliasing, limited palette, contextual dark outline, subtle 1-pixel highlight,
centered, isolated on transparent background, no text, no logo, no watermark,
designed for a 32x32 base grid. Subject: [SUBJECT].
```
