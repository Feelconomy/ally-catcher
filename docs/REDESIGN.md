# Cozy Pixel Claw — 기능 보존 감사

기준 커밋: e07bdef518286b17c6e9c4eaf11a93caf6c692ce (main)
작업 브랜치: redesign/cozy-pixel-claw

## 구조와 보존 경계
- index.html: 정적 앱 셸. 새 스타일시트만 추가.
- js/app.js: 해시 라우터, 접근 가드, 타이머 정리. 변경 금지.
- js/store.js: localStorage, 티켓/포인트/보상/출석. 변경 금지.
- js/data.js: 기계/인형/미션 카탈로그. 변경 금지.
- js/auth.js, sync.js, config.js, supabase/: 인증, 동기화, 서버 계약. 변경 금지.
- js/play.js: 조작, 위치 계산, 확률, 타이머, 판정. 변경 금지. CSS에서도 기하/좌표는 유지.
- js/screens.js, overlays.js, ui.js: 기존 마크업과 핸들러 보존. 공통 CSS 컴포넌트로 재디자인.

## 순서 및 기능 보존 체크리스트
1. 로그인: 카카오 인증, 네이버/Apple 데모 약관 흐름, 둘러보기, 가입/프로필/온보딩 유지.
2. 로비: 필터, 검색, 상세, 점검 상태, 티켓 표시, 숨겨진 관리자 진입 유지.
3. 플레이: 기계별 비용, 20초 제한, 좌우/드래그/키보드, 1회 드롭, 확률과 실패 보너스, 종료/오프라인 처리 유지.
4. 결과: 성공/미끄러짐/빗나감/시간초과, 포인트, 공유, 재시도와 잔액 검증 유지.
5. 컬렉션: 보관함 필터, 중복 교환, 도감, 등급, 포즈 및 관리자 추가 인형 유지.
6. 미션/출석: 자동 출석 누적, 진행도, 보상 중복 방지, 광고 한도, 전체 완료 보너스 유지.
7. 마이: 이름 편집, 레벨, 통계, 교환소/응모/NH 연동/설정/탈퇴 유지.

팩의 제안 중 실제로 없는 재화, 탭, 구매, 출석 페이지는 추가하지 않는다.

## 디자인
Candy 기본, Sky 게임, Honey 미션/보상, Peach 컬렉션. 기존 클래스가 PixelButton, PixelPanel, ItemSlot, RibbonTitle, PixelProgress 역할을 수행한다. 스타일 전용 파일에서 재사용하며 새로운 렌더링/상태 계층은 만들지 않는다.
원본 디자인 팩은 .claude/skills/cozy-pixel-core 및 cozy-pixel-claw에 보관.

## 검증 결과
- 15개 라우트 × 4개 뷰포트(320×568, 390×844, 420×520, 1280×900): 가로 넘침 없음.
- 임시 브라우저에서 둘러보기 → 홈, 키보드 우측 이동 → 드롭 → 결과 전환 통과.
- 브라우저 실행 오류 0건.
- 보호 대상 JS/설정 파일은 기준 커밋과 바이트 단위 동일. screens.js는 배너 이미지 경로 1개만 변경.
- git diff --check 통과. 프로젝트에 빌드/테스트 패키지가 없어 빌드 단계 없음.
- 실제 OAuth, 서버 동기화, NH 전환, 모든 보상 경계값은 외부 연동을 차단한 테스트에서 검증하지 않음.
- 수집 인형의 기존 아트와 4포즈는 식별성과 상태 피드백을 위해 유지. 새 픽셀 기계 아트는 로비에 적용.
